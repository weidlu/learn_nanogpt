# Experiments

这里记录每一次 nanoGPT 学习实验。

建议每次实验复制模板：

[experiment-template.md](experiment-template.md)

命名格式：

```text
YYYY-MM-DD-short-description.md
```

例子：

```text
2026-05-25-shakespeare-cpu-smoke.md
2026-05-26-temperature-comparison.md
2026-05-27-block-size-64-vs-256.md
```

每篇实验记录至少写清楚：

- 改了什么参数
- 运行了什么命令
- 观察到了什么
- 学到了什么
